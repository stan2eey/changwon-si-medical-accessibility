# 같은 창원, 다른 30분

창원 의료접근성 연구 공개 자료집: 스크롤 기사, 지역 탐색 지도, 방법론, 산출표.

## 개발

```sh
npm ci
npm run dev
npm run build
```

Astro 정적 사이트. 기본 경로는 `/changwon-si-medical-accessibility/`입니다.
`npm run build`는 데이터 검증 후 정적 파일을 생성합니다.

배경지도는 VWorld 일반지도와 위성지도(지명 포함)를 사용합니다. `.env.example`을 `.env.local`로 복사하고 `PUBLIC_VWORLD_API_KEY`에 서비스 URL로 등록한 웹지도 키를 설정하세요. `.env.local`은 Git에서 제외됩니다. 웹지도 키는 브라우저 타일 요청과 공개 빌드 파일에 포함되므로 원자료 접근용 비밀키를 사용하면 안 됩니다. 키 만료·등록 URL 변경 시 갱신 후 재빌드하세요. 키가 없으면 격자 SVG 대체지도로 표시합니다. 분석에 사용한 OSM 차량망과 산출값은 배경지도 변경과 무관합니다.

## 데이터

`public/data`에는 공개용 파생 결과만 들어 있습니다. 지도는 선택한 서비스·30/60분 결과를 나누어 불러옵니다. 도로망·원자료·API 응답·격자별 성/연령 인구·인증키는 포함하지 않습니다.

현지 연구환경에서 내보내기:

```sh
python scripts/export_research.py <연구의_접근성분석_폴더>
python scripts/make_static_map.py
npm run build
```

내보내기는 기존 203번 분만 코드의 입력·계산을 사용하고 원자료를 수정하지 않습니다. 필요 패키지: numpy, pandas, scipy, shapely, pyproj, openpyxl. 재현 결과는 기존 분만 민감도표의 평균점수와 대조합니다. 원본 파일명·해시는 `public/data/provenance.json`에 기록됩니다.

## 공개 기준

- 기관등록 상세분석 2026.10, 의료인력 비교 2026.06을 분리합니다. 비교 인구는 2026.09이며 산부인과는 여성, 소아청소년과는 0~19세, 나머지는 전체 주민이 분모입니다.
- 분만 점수의 수요는 연간 기대출생아입니다. 여성인구 비율은 별도 필드로 보존합니다.
- 초과지역 비율은 전체 대상인구 기준, 평균점수는 계산된 격자의 수요 기준입니다.
- 배편·미산출을 0점으로 대체하지 않습니다.
- 이 사이트는 실제 진료·응급수용을 안내하지 않는 개인 연구 자료집입니다.
- 원고에서 미해결된 표현은 그대로 게시하지 않으며 웹의 기준표는 자료 페이지에 명시합니다.

## 배포

현재 공개 사이트는 검증된 `dist/`를 `gh-pages` 브랜치에서 게시합니다. GitHub Pages 설정은 **Deploy from a branch → gh-pages → /(root)** 입니다. main의 코드 변경만으로는 사이트가 갱신되지 않습니다.

배포 전에는 `npm run build`, `npm test`, `python scripts/check_site.py`를 실행합니다. 검증 후 `dist/`의 파일과 `.nojekyll`을 gh-pages에 반영합니다.

자동배포 템플릿은 `deploy/pages-workflow.yml`에 있습니다. 워크플로 파일 쓰기 권한을 가진 계정으로 이를 `.github/workflows/pages.yml`에 등록하고 Pages Source를 **GitHub Actions**로 변경하면 main의 변경이 검증·빌드를 거쳐 자동 게시됩니다. 현재 연결 앱의 워크플로 쓰기 권한 제한 때문에 자동배포는 활성화하지 않았습니다.

## 라이선스

사이트 코드는 MIT입니다. 제3자 데이터·경계·지도영상 및 라이브러리에는 각 제공자의 조건이 별도로 적용됩니다. 데이터 재사용 시 연구 버전과 정의·출처를 함께 표기하세요.
창원시 의료접근성 분석 결과를 탐색하는 인터랙티브 지도입니다. 8개 진료과와 분만 서비스의 지역별 접근성 점수, 추정 이동시간, 도달 가능한 의료기관 수를 비교하고, 위성지도와 함께 관심 지역을 살펴볼 수 있습니다. 분석 수식과 연구방법론 및 읍면동별 요약 결과도 함께 제공합니다. 본 자료는 창원시의회 정책연구보고서(플라토 2.0)의 자료를 바탕으로 재구성된 자료입니다.

## 도시 비교·격자 탐색 확장 (2026.10.30)

- `/cities/`: 창원 + 17개 비교지역 + 특례시 4곳. 원 산출표의 실제 등록인원·분모인구를 사용하며 반올림 공급률에서 인원을 역산하지 않습니다.
- `/explore/`: `grid_id`로 선택 격자를 복원합니다. 격자 클릭은 지역 선택·비교표·상세 카드에 함께 반영됩니다.
- WebGL 실패 시 동일한 공개 형상·값의 SVG 지도로 확대·이동·선택합니다. 본문은 장면별 실제 결과 SVG를 먼저 표시합니다.
- `python scripts/export_workforce_q2.py`: 최종 보고서의 2026년 6월 의료인력 원자료에서 22개 도시와 창원 5개 구를 추출하고 집단 공급률을 대조합니다. 기존 `export_cities.py`는 과거 9월 자료용입니다.
- `python scripts/make_result_maps.py`: 공개 데이터에서 정적 결과지도 생성.
- `npm test`: 지도 성공 경로의 선택 이벤트, WebGL 실패 대체, 공유 격자 복원, 지표 연동, 도시별 정렬·비교를 DOM에서 검사합니다. 실제 브라우저 렌더링 검수와는 별개입니다.
